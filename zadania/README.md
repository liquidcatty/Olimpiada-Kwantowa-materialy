## 5. Kolejność pracy (zalecana)

1. Rozdział teorii → przykłady rozwiązane (przepisz z pamięci) → zadania Z-NN.
2. Po module: praca domowa PD-N.
3. Po module 2 i 3: wróć do **P1–P4** i rozwiąż je bez patrzenia — to test
   gotowości na zadania typu olimpijskiego.
