## Jak z nich korzystać

1. **Najpierw spróbuj sam** — arkusz jest krótki (4 zadania), a poziom „orientacyjny”
   oznacza, że zadania Etapu I będą podobne lub trudniejsze.
2. Zapisz rozwiązania na kartce, mierząc czas (realistycznie: 60–90 minut na cały
   zestaw).
3. Dopiero potem zajrzyj do [rozwiązań modelowych](rozwiazania-P.md).
4. Sprawdź się numerycznie: `python kod/verify_all.py` (skrypty `p1`–`p4` liczą
   dokładnie te same wielkości).
