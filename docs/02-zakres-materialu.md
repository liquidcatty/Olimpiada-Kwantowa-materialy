## 4. Jak czytać ten zakres

- **15.11.2026–28.02.2027** (Etap I): przerobić rozdziały 01–16 + PD-1…PD-4.
- **Przed rozmową Etapu II**: powtórzyć **własne rozwiązania z Etapu I** i umieć je
  obronić (rozdział `docs/05-przygotowanie-do-etapu-2.md`).
- **Przed finałem**: rozdziały 17–20, mini-projekty, praca z danymi.
